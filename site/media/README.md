# Media availability

This public package contains one `showcase-montage.mp4` (40 seconds) plus its contact-sheet poster. The montage contains five real two-second cases; each case repeats four times for an 8-second segment. All come from one checkpoint; no new inference was performed. Left: decoded input. Right: prediction-only overlay. GT geometry is never displayed. GT/prediction captions, driving suggestions, and the observation are embedded inside the lower part of the montage. The page adds only a timing/title/observation guide, not a duplicate caption comparison. The accessible video label follows the active case.

Research preview / offline inference / hand-selected. Display permissions and publication approval are user-confirmed, not independently legally verified. Imagery is retained without additional blurring after review of the 50 unique displayed frames.
